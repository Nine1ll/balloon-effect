# Balloon Effect

### 대출 규제로 막힌 신용수요는 어디로 이동하는가?

> **대출 규제가 신용수요를 없애는 것이 아니라, 더 비싸고 위험한 금융상품으로 이동시키는 것은 아닐까?**

`balloon-effect`는 주택담보대출 등 주요 대출에 대한 규제가 강화되었을 때, 차주의 자금 수요가 **신용대출·마이너스통장 → 카드론 → 리볼빙·현금서비스** 등 상대적으로 위험도가 높은 금융상품으로 이동하는 **신용 풍선효과(Credit Balloon Effect)를** 차주 단위의 상태 전이 관점에서 시뮬레이션하고 시각화하는 프로젝트입니다.

실제 차주 미시데이터를 사용할 수 없는 상황에서 공개된 금융시장 자료를 바탕으로 **규제 전·후 전이확률을 설계하고 합성 차주 데이터를 생성**하여, 규제 이후 신용수요의 이동 경로를 대시보드에서 확인할 수 있도록 구현했습니다.

---

## 1. 문제의식

대출 규제가 강화되면 단순히 "대출이 줄어든다"고 생각하기 쉽습니다.

하지만 실제 금융시장에서는 기존 대출이 막힌 차주가 다른 금융상품을 찾을 수 있습니다.

```text
                    대출 규제
                       │
                       ▼
                 주담대 수요 제한
                       │
                       ▼
                신용대출·마통
                       │
                       ▼
                    카드론
                       │
                       ▼
             리볼빙·현금서비스
                       │
                       ▼
                 차주의 부담 증가
```

따라서 중요한 질문은 **대출 총량이 얼마나 감소했는가**뿐만 아니라,

> **"규제로 인해 차주의 신용 상태가 어느 방향으로 이동했는가?"**

입니다.

이 프로젝트는 이 문제를 **차주 × 월 × 금융상품 상태(state)의** 전이 문제로 바라봅니다.

---

## 2. 프로젝트 목표

### 핵심 질문

1. 대출 규제 이후 차주가 더 위험한 금융상품으로 이동하는가?
2. 어떤 금융상품 간 이동이 가장 크게 나타나는가?
3. 규제 이후 `card → revolving`과 같은 하강 전이가 증가하는가?
4. 이러한 전이를 조기에 발견하여 취약차주에 대한 선제적인 대응에 활용할 수 있는가?

---

## 3. 핵심 아이디어

차주의 금융상품 상태를 하나의 상태(state)로 정의합니다.

| 상태 | 의미 | 위험도 |
|---|---|---:|
| `mortgage` | 주택담보대출 | 1 |
| `deposit` | 예금은행 | 1 |
| `credit` | 신용대출·마이너스통장 | 2 |
| `card` | 카드론 | 3 |
| `revolving` | 리볼빙 | 4 |
| `cleared` | 상환·이탈 | - |

그리고 차주의 상태가 월별로 어떻게 이동하는지 추적합니다.

```text
mortgage
   ↓
credit
   ↓
card
   ↓
revolving
```

각 차주의 월별 경로를 생성한 뒤, 이전 상태와 다음 상태를 비교하여 **전이행렬(Transition Matrix)을** 산출합니다.

---

## 4. 규제 전·후 비교

규제 전에는 금융상품 상태가 비교적 안정적으로 유지된다고 가정합니다.

반면 규제 이후에는 대출 수요의 대체 경로가 발생한다고 가정합니다.

### 규제 전

```text
유지 확률 ↑
하강 전이 ↓
상환 확률 상대적으로 높음
```

### 규제 후

```text
mortgage → credit     ↑
deposit  → credit     ↑
credit   → card       ↑
card     → revolving  ↑↑
상환·이탈              ↓
```

특히 카드론 규제 이후 현금서비스·리볼빙 등으로 이동하는 현상을 반영하여 `card → revolving` 전이를 강화했습니다.

## 5. Dashboard

Streamlit 기반 대시보드에서 차주들의 상태 변화를 다음과 같이 확인할 수 있습니다.

### ① 상품별 차주 수 추이

월별로 각 금융상품에 속한 차주 수가 어떻게 변화하는지 확인합니다.

### ② Sankey Diagram

특정 월에서 다음 월로 넘어가면서 차주가 어떤 금융상품으로 이동했는지 보여줍니다.

```text
주담대 ────────→ 신용대출 ─────→ 카드론 ─────→ 리볼빙
```

이를 통해 단순한 잔액 변화가 아니라 **자금의 이동 경로**를 확인할 수 있습니다.

### ③ 전이행렬

각 금융상품에서 다른 상품으로 이동할 확률을 행렬 형태로 확인합니다.

### ④ 위험 전이 경보

현재 상태보다 위험도가 높은 상품으로 이동한 차주를 찾아

- 2금융권 하강
- 상위 위험군 진입
- 리볼빙 등 고위험 상품 진입

등의 후보를 조기에 탐지합니다.

## 9. 데이터 및 분석의 한계

이 프로젝트에서 사용한 차주 데이터와 상태 전이확률은 **실측 차주 데이터가 아닌 합성 데이터**입니다.

차주 단위의 실제 전이율은 KCB·신용정보원 등의 미시데이터가 필요하기 때문에, 공개된 집계 통계를 이용하여 **전이 방향과 상대적인 크기**를 보정하고 나머지는 합리적인 가정으로 구성했습니다.

따라서 본 프로젝트의 결과를 실제 금융기관의 전이율이나 연체율로 해석해서는 안 됩니다.

대신,

> **"규제 → 대체 금융상품 → 위험도 상승"이라는 금융 현상을 차주 단위 상태 전이 모델로 어떻게 구조화하고 분석할 수 있는가**

를 보여주는 **프로토타입**에 목적이 있습니다.

실제 금융기관에서 활용한다면 `build_panel()`을 실제 여신 데이터 로딩 과정으로 교체하고, 동일한 전이행렬 산출 파이프라인을 이용하여 실측 데이터를 분석할 수 있도록 설계했습니다.

## 10. 데이터 설계의 근거

전이확률은 다음과 같은 공개 자료를 참고하여 설계했습니다.

- 카드론 규제 이후 현금서비스·리볼빙으로 이동하는 풍선효과
- 카드론 감소분을 현금서비스·리볼빙이 대체하는 현상
- 은행 대출이 어려워진 중·저신용 차주의 은행 밖 급전창구 이동
- 대출잔고 및 차주의 상환부담과 연체확률 간 관계

상세한 출처와 각 확률에 반영한 내용은 [`REFERENCES.md`](./REFERENCES.md)에 정리했습니다.

## 11. 향후 발전 방향

### 실제 데이터 적용

합성 데이터를 실제 차주 데이터를 대체하여 다음을 분석할 수 있습니다.

```text
차주 ID
  ×
  월
  ×
 상품
  ×
 잔액
  ×
신용등급
```

이를 기반으로 실제 전이행렬을 산출하고 취약차주의 이동 경로를 분석할 수 있습니다.

### 개인 단위 조기경보

단순히 "리볼빙 이용자가 증가했다"는 집계 수준을 넘어,

> `신용대출 → 카드론 → 리볼빙`

과 같이 **위험도가 연속적으로 상승하는 차주**를 탐지하여 개인 단위 조기경보 시스템으로 확장할 수 있습니다.

### 취약차주 세그먼트 분석

신용점수, 소득, DTI, 대출잔액 등의 정보를 결합하여 어떤 차주군에서 풍선효과가 강하게 나타나는지 분석할 수 있습니다.
